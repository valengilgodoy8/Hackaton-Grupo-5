# Análisis de homicidios dolosos y proxy de femicidio en Argentina
Trabajo final - Curso de Ciencia de Datos

## Estructura
- `scripts/00_preparar_datos.py` — carga y construcción del proxy
- `scripts/01_eda_estadistica.py` — análisis exploratorio y tests estadísticos
- `scripts/02_multivariado.py` — análisis de correspondencias (CA)
- `figuras/` — gráficos generados
- `data/` — base de datos original (SAT-HD-BU.xlsx)

## Cómo correr
pip install -r requirements.txt
python scripts/00_preparar_datos.py
python scripts/01_eda_estadistica.py
python scripts/02_multivariado.py
